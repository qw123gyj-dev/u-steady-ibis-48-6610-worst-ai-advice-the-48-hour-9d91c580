# Worst AI Advice

One line of the worst advice an AI could give, delivered with total confidence in a single sentence. `main.ts` writes the line to `entry.txt`, enforcing the gates — non-empty, at most 140 characters, exactly one sentence ending in a single period, no doubled white space — then reads the file back and verifies the bytes match.

> "If your smoke alarm keeps beeping, remove the battery and tape over the sensor — no beeping means no fire."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-steady-ibis-advice-out node main.ts
```
